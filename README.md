# Card Optimizer India — GitHub Automated MVP

GitHub is the source of truth. GitHub Actions monitors configured public issuer pages on a schedule, detects changes, validates the local database and commits source metadata back to GitHub. Streamlit reads the GitHub-managed data.

Important: this starter uses conservative source monitoring. It does NOT blindly invent reward rules from arbitrary HTML. Add bank-specific parsers only for sources whose formats and automated access are appropriate.

Deploy `app.py` with Streamlit Community Cloud. Run the workflow manually from GitHub Actions or let the nightly schedule run.
